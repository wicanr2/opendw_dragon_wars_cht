**一個重要的文件校正**:`docs/assessment/48`/`49`(06-15 快照)主張「跨區連通 <10%、主線幾乎走不通、終戰地進不去」。**這已被後續動態逆向工作推翻**——我實跑 `verify_mainline_reachable`,當前 binary 從波卡城 flood-fill **可達 38/40**(含 area 27 終戰地),只缺 {6,33} 菲巴斯隔離分量。讀舊快照容易誤判「不能破關」,以本報告實測為準。

## 2. 能不能破關(破關鏈逐段驗證)

破關真值(攻略 38/39):波卡城開局 → 序盤逃脫 → 中期收集(拉娜碎片/眼鏡/船票)→ 後期(鑄自由之劍 + 取龍寶石)→ 尼塞山腹決戰 Namtar → 結局。我逐段實跑驗證:

| 段落 | 我跑了什麼 | 結果 | 卡點 / 風險 |
|---|---|:---:|---|
| **建角** | `--newgame --frames 2` dump | ✅ 繁中「火龍之戰」+「建立人物 (0/4)」+「輸入名字」+「Enter:確認 Esc:取消」+ [繁中] 語言指示 | 無;`verify_chargen` ctest 綠 |
| **探索(第一人稱)** | `--map 1 --fp --frames 2` dump | ✅ EGA 透視走廊 + 隊伍面板 + 繁中操作列;`render_sweep` 全 40 關 154 case byte-for-byte | 無 |
| **跨區連通** | `verify_mainline_reachable assets/bundle` | ✅ **波卡城 BFS 38/40**,世界圖樞紐邊 27 + 子區 relocate 24 + 直接 gs[2] 進入 16 | 缺 {6,33} 菲巴斯(隔離分量,正向入邊逆不出);area 27 已連通(4→27、18→27) |
| **主線事件繁中** | `--map 1 --at 13 20 --frames 0` dump | ✅ 半透明框 + 繁中開場敘事(波卡城貧民窟序盤),自動分頁 | 中後期內容深度仍是天花板(見 §5) |
| **終戰 Namtar** | `--fight-namtar --combat-rounds 30 --frames 3` | ✅ `outcome=1 Victory, mon_alive=0, xp=80`,進入結局(scenes=5);多 seed 確定性可勝(`verify_ending` E1 7 seed) | Namtar 屬性/自由之劍祝福 = remake 平衡設計(非原版真值,誠實標示) |
| **結局** | `--ending --frames 1` / `--para-scroll 2` dump | ✅ 真實場景圖(scene 24.pic 等 5 幀)+ 繁中字幕「將納達拋回祂當初竄出的那座深淵……」+ remake 組合標示 | 結局序列 = remake 組合(bundled 段落 + area27 敘事真實素材;串接是設計) |

**破關鏈結論**:**設計上可從建角走到結局**,六段全部親跑、零 crash、繁中正常。

**誠實揭露兩點影響破關「忠實度」(非可玩性)的事**:
1. **連通靠動態 RE 逆出的三套換區機制**(世界圖樞紐 + 子區 relocate + 直接 gs[2] 進入),非 oracle byte 對拍——`opendw` 自身對 wrap 邊界是 `exit(1)` 未實作,remake 用乾淨室慣例補上並可走動。{6,33} 菲巴斯分量正向入邊在所有可解碼 bytecode 中找不到(54 §2.4 窮舉證實),屬隔離區;菲巴斯不在終戰必經路徑上,**不阻斷破關**。
2. **終戰 + 結局是 grounded 設計**:Namtar Boss 屬性(HP=120/AV5/DV6)、自由之劍祝福加成、結局串接都是 remake 平衡/組合,因為原版勝利畫面由 DRAGON.COM 主控、不在任何 level script(掃全 40 關證實),逆不出單一 oracle 腳本。**能贏、能看結局是真的;「跟原版逐欄一樣」不成立**。

**soft-lock 風險**:headless 端到端我未模擬「互動移動逐格踩到 area27 觸發 Namtar」的完整人工走法(in-game 觸發與 `--fight-namtar` 共用同一 `begin_namtar` 路徑,但人工逐格注入未跑,見 56 §6.3)。理論連通已驗(BFS 可達),戰鬥/結局入口已驗,但「一個真人不靠旗標,純鍵盤從波卡城走到 area27」這條完整人工路徑未做端到端回放——這是破關鏈唯一未被機器閉環蓋章的縫隙。

## 4. 能不能重回童年(體驗保真)

### 4.1 視覺保真(會認得)

| 畫面 | 我看到的 | 對 1989 的還原 |
|---|---|---|
| 開機標題 | 綠龍張口 + 紅衣戰士立繪 + 金字「Dragon Wars」+「Copyright Interplay 89-90」+ 繁中「火龍之戰」+「按任意鍵繼續」 | **高**:原版 DOS res29 立繪,老玩家一眼認出 |
| 第一人稱地牢 | EGA 灰石牆 + 紅地 + 綠色裝飾邊框 + 右側「Dragon Wars」面板 + 4 血條 | **高**:逐像素對拍 opendw |
| 戰鬥 | 怪物立繪 @golden 佈局 + 繁中指令列 | **高**:sprite byte-for-byte |
| 段落書 | 「段落 88」整頁譯文 + dither 半透明背景 + 翻頁指示 | **高**:還原防拷手冊查閱儀式感 |
| 事件框 | 深藍 dither 3/4 半透明 + 雙線藍框 + 24px 銳利 CJK | **高**:文字層恆銳利,優雅 |
| 結局過場 | 納達崩解藝術圖 + 繁中字幕「換字不換版」 | **中高**:有藝術圖不是純文字 |

### 4.2 操作手感

符合「ESC 只 cancel、F10 才離開、離開前自動存檔 + 確認」鐵則;快捷字母(B 開始/C 繼續)+ 方向鍵輔助,對齊原版手冊。底部恆駐繁中操作提示列降低上手門檻。

### 4.3 繁中在地化品質

- **覆蓋**:menu/chars/combat/items/spells/shop 全繁中;i18n 587 條;主線事件繁中 200+ 鍵 + 147 段落 + 結局;可達英文回退從 74 條壓到 1 條(雜訊)。
- **品質**:譯文自然,非翻譯腔。「奉深淵之獸納達之命」「將納達拋回祂當初竄出的那座深淵」這類句子有 CRPG 史詩感,譯名對齊 CONTEXT.md(Namtar→納達、Irkalla→伊爾卡拉、波卡城/瑪根地底世界)。
- **加值**:F4 三語(繁中/英/日),日文 events 為 X68000 原文反萃取——這是超原版的考古加值。

### 4.4 會心一笑點 vs 出戲點

**會心一笑**:
- 綠龍標題畫面原汁原味,連 Interplay 版權年「89-90」都在。
- 段落書防拷機制完整重現——當年要翻實體手冊找段落號的儀式,現在繁中可捲動。
- 第一人稱走廊那個綠色裝飾邊框,是 Dragon Wars 的招牌視覺。

**出戲點(誠實寫死)**:
- **全程靜音**:無音訊子系統(op_90 忠實 no-op);65 報告稱「音訊 40%」指有 SDL2 合成 + 3 段 PCM 子系統存在,但事件→音效對映 + 互動播放在我跑的路徑未觸發,實質聽感仍接近靜音。原版的 PC speaker 音效回饋是童年記憶一部分,這塊最缺。
- **隊員名英文**(Muskels/Theb/Elendil/Cheetah):512B player_record 的 7-bit 高位元終止編碼容不下 CJK,改譯會破存讀檔 byte-for-byte golden(B3 保留項,玩家可自由改名)。
- **結局是組合非原版單一過場**:有藝術圖 + 繁中,但老玩家若記得原版確切的勝利畫面流程,會感覺「神似但不是同一個」。

## 6. 發布建議

### 可以給朋友玩了嗎?

**可以——對「童年玩過、想重溫」的發起人,現在就能交付。** 它能從建角玩到結局、全程繁中、四種復古畫風隨按隨換,核心 CRPG 循環(探索→戰鬥→升級→買裝→招募)全接通,零 crash。作為「重溫載體」已過門檻。

**交付時要誠實講清楚的限定詞**(README 誠實邊界已寫,維持即可):這是高保真重製,核心引擎逐位元對拍原版,但**成長/結局/連通是 grounded 重建,不是 100% oracle 真值;全程靜音**。

### 還缺哪幾項才算「能完整重溫」(優先序)

| 優先 | 項目 | 為何 | 量級 |
|:---:|---|---|:---:|
| ⭐ 1 | **錄一條無旗標人工破關 demo(消 R1)** | 把「設計上可破關」升級成「親眼看著從波卡城走到結局」的鐵證;這是發布前最值得補的一次驗證,直接回應發起人「能不能破關」 | S |
| 2 | **接上音訊事件播放(消 R6)** | 子系統 + PCM 已就緒,缺事件→音效的互動觸發;音效是童年記憶最缺的一塊,補上重溫度從 7 成往 8 成走 | S–M |
| 3 | **中後期 quest gate 串成體系 + 內容在地化完整化(消 R3)** | 系統已齊,天花板在內容;把「持有 X 解鎖 Y」串成因果主線,是把可玩性從 ~68% 拉向 80% 的主路徑 | L |
| 4 | **打包發佈(Linux 包已驗,補 Win/macOS)** | 系統與可玩性已過門檻,值得讓外部體驗 | S–M |
| 5 | **怪物屬性 + res3 全戰鬥閉環真值化(消 R4)** | 忠實度潔癖項,玩家可感價值低,留最後 | L–XL |

**一句話發布建議**:**先補 1(人工破關 demo)+ 2(音訊),這兩項小成本、直接命中「能不能破關」與「能不能重回童年」兩個核心問題;之後 3(內容)是長期主路徑。現在交給發起人玩,體驗已經對得起那條綠龍。**
